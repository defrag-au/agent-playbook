If you need to find out information on a crate that's suggested to you then consult crates.io to find the current verison and find a link back to the appropriate source code repository.  This is more reliable than attempting to do an internet search.  The repository will almost always be listed on the crate summary page (https://crates.io/crates/{crate})

When doing research in the github repo you should look at the README and then also look at examples provided in the repo to get a feel for sample usage.  In the instance that we choose to proceed with a particular crate, you should also create a cheat sheet document (in a format that you understand) so you can deal with that version of the crate as well as possible even if you weren't pretrained on the crate.  Be as detailed as you need.
