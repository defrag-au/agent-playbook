# cef 156.2.0 (tauri-apps/cef-rs)

## At a glance

- This is the **tauri-apps fork**, not the older `cef` crate on crates.io: bindings are generated
  per target, and `wrap_app!` / `wrap_browser_process_handler!` / `wrap_client!` build the
  ref-counted wrappers you implement traits on.
- **The crate version encodes the distribution.** `156.2.0+156.0.14` is crate 156.2.0 speaking
  CEF 156.0.14. `cef-dll-sys` derives that from its own version and downloads the archive if
  `CEF_PATH` does not already hold it (about 1 GB).
- `sys::CEF_API_VERSION_LAST` + `api_hash(.., 0)` run before any other call.
- `execute_process` is the re-exec entry, not `execute_process_from`. Browser process → `-1`;
  a child → `>= 0`, and the child does **not** call `initialize`.
- This sheet answers "start CEF, open one window, and get a frame out of it".

## Cargo.toml

```toml
cef = { version = "=156.2.0", default-features = false }
```

`cargo` ignores the `+156.0.14` build metadata and warns about it, so the requirement is the
plain version; the distribution version comes from the crate's own version string.

Features: `sandbox` (Windows bootstrap), `build-util` (bundle tooling), `resources`,
`accelerated_osr` (texture import), `dox` (bindings without the distribution).
`default = ["sandbox", "build-util", "resources"]`.

## Boot a browser process

The shape from `examples/cefsimple/src/shared/mod.rs`, which is the reference:

```rust
use cef::*;

// macOS loads the framework itself; elsewhere it is linked.
#[cfg(target_os = "macos")]
let _library = {
    let loader = library_loader::LibraryLoader::new(&std::env::current_exe()?, false);
    assert!(loader.load());
    loader
};

let _ = api_hash(sys::CEF_API_VERSION_LAST, 0);

let args = cef::args::Args::new();                 // wraps argc/argv
let cmd_line = args.as_cmd_line().expect("command line");

let type_switch = CefString::from("type");
let is_browser_process = cmd_line.has_switch(Some(&type_switch)) != 1;

let ret = execute_process(Some(args.as_main_args()), None, std::ptr::null_mut());
if !is_browser_process {
    std::process::exit(ret.max(0));
}
assert_eq!(ret, -1, "browser process must return -1 from execute_process");

let mut app = MyApp::new();
let settings = Settings {
    no_sandbox: true as _,                          // required when `sandbox` is off
    ..Default::default()
};
assert_eq!(initialize(Some(args.as_main_args()), Some(&settings), Some(&mut app), std::ptr::null_mut()), 1);

run_message_loop();
shutdown();
```

## Open one windowed browser

`on_context_initialized` is where a browser process is ready for its first window:

```rust
wrap_app! {
    pub struct MyApp;
    impl App {
        fn browser_process_handler(&self) -> Option<BrowserProcessHandler> {
            Some(MyBrowserProcessHandler::new())
        }
    }
}

wrap_browser_process_handler! {
    struct MyBrowserProcessHandler;
    impl BrowserProcessHandler {
        fn on_context_initialized(&self) {
            let window_info = WindowInfo {
                runtime_style: RuntimeStyle::DEFAULT,
                ..Default::default()                    // windowed: windowless is opt-in
            };
            let created = browser_host_create_browser(
                Some(&window_info),
                None,                                   // a Client if you want load callbacks
                Some(&CefString::from("https://example.com/")),
                Some(&BrowserSettings::default()),
                None,
                None,
            );
            assert!(created != 0);
        }
    }
}
```

`browser_view_create` + `window_create_top_level` is the Views path (`--use-native` in the
example selects the plain native window). The wrapper macros accept struct fields, which is how
the example carries its `url` and `client` into the handler.

## Import an OSR frame into wgpu

With `features = ["accelerated_osr"]`, the crate does what `welding` used to be needed for —
IOSurface/Metal, D3D11 through DX12 or Vulkan, DMA-BUF through Vulkan:

```rust
use cef::osr_texture_import::SharedTextureHandle;

// Inside the accelerated-paint callback, with a device/queue on the same GPU as CEF.
let texture: wgpu::Texture =
    unsafe { SharedTextureHandle::new(info).import_texture(device, queue)? };
// The texture can be kept after the callback returns; the import waits for the copy.
```

Vulkan devices need `wgpu::Features::VULKAN_EXTERNAL_MEMORY_DMA_BUF` (Linux) or
`..._WIN32` (Windows). Import failure falls back to software `on_paint`.

## Gotchas

- **`api_hash` first**, then args, then `execute_process`, then `initialize`. A child process
  must return without initialising.
- **`switch_value` returns `CefStringUserfreeUtf16`**, which has no `Display` and no
  `to_string()`. Wrap it: `CefString::from(&cmd_line.switch_value(Some(&switch))).to_string()`.
- **`no_sandbox` must agree with the feature.** Building without `sandbox` and leaving
  `no_sandbox: false` starts and then fails to create a browser.
- **macOS needs a bundle, and the helper apps are copies of your own binary.** `LibraryLoader`
  resolves `../Frameworks` from the executable, so the binary must be in
  `<App>.app/Contents/MacOS/`; the minimal distribution `cef-dll-sys` downloads ships no
  `.app` helpers, so you create `<Name> Helper.app` (base, GPU, Renderer, Plugin, Alerts)
  containing the same executable. Missing them gives `error_code=1003` and then
  `GPU process isn't usable. Goodbye.`
- **`RuntimeStyle::DEFAULT` is Chrome UI**, not "the default window": a tab strip and toolbar
  around your page. `RuntimeStyle::ALLOY` is a plain window holding only the web content.
- **`--use-mock-keychain`** in `on_before_command_line_processing`, or Chromium asks macOS for
  the Safe Storage key at startup.
- **`dox` type-checks without the distribution** — `cargo check --features dox` compiles the
  generated bindings with a no-op build script. It catches signature errors before a 1 GB
  download, and proves nothing at runtime.
- Standard CEF builds omit H.264/AAC and Widevine.
