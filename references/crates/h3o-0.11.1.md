# h3o 0.11.1 (HydroniumLabs/h3o)

## At a glance

- Pure-Rust H3 (Uber's hexagonal hierarchical index). BSD-3-Clause, edition 2024.
- **No wasm-bindgen on wasm32-unknown-unknown.** The only `getrandom` is inside
  `ahash`'s `const-random` proc-macro, which runs on the host at build time.
  Safe for macroquad.
- Cells are `CellIndex` (a `u64`). Resolutions are `Resolution::Zero..=Fifteen`
  (aperture 7). Every resolution has exactly **12 pentagons** at fixed places.
- **Ordering trap:** `grid_disk_safe` (the slow path `grid_disk` falls back to
  near pentagons) collects through an `ahash` set seeded at compile time, so
  its order can differ between builds. Sort results if determinism matters.
- `grid_distance`, `grid_path_cells` and `to_local_ij` return `Err` across a
  pentagon, **and between cells too far apart to unfold onto one plane**
  ("cannot unfold (base cells are not neighbors)"), which hits ordinary
  continent-scale distances. Plan for the error rather than unwrapping. For an
  A* heuristic, fall back to the centre-to-centre angle divided by
  `2√3 × edge_length_rads()`.
- No A* inside. Pair it with the `pathfinding` crate (4.16), using
  `grid_disk(1)` as the successor function.
- This sheet answers: direction or lat/lng → cell, cell → centre/outline,
  rings, distance, flat local coordinates, and pentagons.

## Cargo.toml

```toml
h3o = "0.11.1"          # default feature `std` (ahash). Optional: serde, geo.
pathfinding = "4.16"    # if you need A*; MSRV 1.88
```

## Lat/lng ↔ cell

```rust
use h3o::{CellIndex, LatLng, Resolution};
let ll = LatLng::new(lat_deg, lng_deg)?;              // or LatLng::from_radians(lat, lng)?
let cell: CellIndex = ll.to_cell(Resolution::Three);
let centre: LatLng = LatLng::from(cell);              // .lat() .lng() degrees, .lat_radians() .lng_radians()
let outline: h3o::Boundary = cell.boundary();         // derefs to &[LatLng]: 6 corners (5 for a
                                                      // pentagon, more where a cell crosses an icosahedron edge)
cell.is_pentagon();
Resolution::Three.pentagons();                        // iterator of the 12
Resolution::Three.edge_length_km(); .area_km2(); .cell_count()  // Earth-scale constants
```

## Rings, distance, paths

```rust
let ring: Vec<CellIndex> = cell.grid_disk::<Vec<_>>(1);   // includes `cell`; 7 (6 at a pentagon)
let d: Result<i32, _> = a.grid_distance(b);               // Err across a pentagon or far apart
let line = a.grid_path_cells(b)?;                         // straight hex line, not a cost-aware path
a.is_neighbor_with(b)?;
cell.parent(Resolution::Two); cell.children(Resolution::Four);   // hierarchy (inexact containment)
```

A* with `pathfinding`:

```rust
pathfinding::directed::astar::astar(
    &start,
    |&c| { let mut n = c.grid_disk::<Vec<_>>(1); n.retain(|&x| x != c); n.sort_unstable();
           n.into_iter().filter_map(|to| cost(c, to).map(|k| (to, k))).collect::<Vec<_>>() },
    |&c| c.grid_distance(goal).map_or(0, |d| d as u32 * min_step),   // admissible, but 0 when it errs —
                                                                     // see world-hex `steps_at_least` for a real bound
    |&c| c == goal,
);
```

## Flat local coordinates (a regional hex map)

```rust
use h3o::{CoordIJ, LocalIJ};
let ij: LocalIJ = cell.to_local_ij(anchor)?;          // ij.coord.i, ij.coord.j; Err across a pentagon
let back = CellIndex::try_from(LocalIJ::new(anchor, CoordIJ::new(i, j)))?;
```

Exact on the hex grid near `anchor`. Keep regional maps away from pentagons.

## Using it on a non-Earth sphere

H3 is defined on a unit sphere; km figures assume Earth. To map a world
direction `d` (pole +y) in: `lat = asin(d.y)`, `lng = atan2(d.z, d.x)`. Rotate
`d` first to move the 12 pentagons somewhere harmless (the sea). The widest
pentagon-free cap has a radius of about 37°, so a continent can always be
cleared if it fits in one. A worked wrapper is `shared-crates/procedural/world-hex`:
`Frame`, `neighbours`, `disk`, `path`, `Patch`, `samples`.
